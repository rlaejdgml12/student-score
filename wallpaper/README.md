# 갤럭시 Z 폴드8 울트라 흑백 배경화면

사진 1장으로 다음 5개 파일을 만듭니다.

| 파일 | 크기 | 용도 |
| --- | --- | --- |
| `이름_main_home.jpg` | 2256 x 2504 | 메인(펼친) 화면 홈 |
| `이름_main_lock.jpg` | 2256 x 2504 | 메인 화면 잠금 (어두운 버전) |
| `이름_cover_home.jpg` | 1080 x 2520 | 커버 화면 홈 (메인의 왼쪽 절반) |
| `이름_cover_lock.jpg` | 1080 x 2520 | 커버 화면 잠금 (어두운 버전) |
| `이름_preview.jpg` | - | 4장을 나란히 놓고 위젯 위치를 겹쳐 본 확인용 |

## 사용법

```bash
pip install pillow numpy
python3 make_wallpapers.py 사진.jpg --name moon
```

자주 쓰는 옵션:

- `--focus-x 0.7` : 가로로 어디를 잘라낼지 (0 = 왼쪽 끝, 1 = 오른쪽 끝)
- `--focus-y 0.4` : 세로로 어디를 잘라낼지 (0 = 위, 1 = 아래)
- `--zoom 1.2` : 조금 더 확대
- `--flip` : 좌우 뒤집기 (주인공을 오른쪽으로 옮길 때)
- `--lock-brightness 0.3` : 잠금 화면 밝기 (기본 30%)
- `--spot 0.72 0.45 0.25` : 잠금 화면에서 밝게 남길 부분 (메인 기준 가로 위치, 세로 위치, 반지름)

## 미리보기 보는 법

- 파란 상자: 남길 위젯·아이콘 자리 (G80, 날씨, 앱 아이콘, 검색창, 독)
- 빨간 테두리: 삭제 예정인 캘린더 자리
- 노란 점선: 주인공을 둘 세로 30~64% 구간
- 흰 세로 점선: 메인 화면의 접히는 선 (왼쪽이 커버 화면에 보이는 부분)
- 메인 화면 오른쪽 절반의 아이콘은 폴더로 정리할 예정이라 상자를 그리지 않았습니다.
