## 07 정렬·중복·제한 연산

- **sorted** — 자연 순서 vs Comparator: 인자 없이 쓰면 Comparable(자연 순서)로, `sorted(comparator)`처럼 인자를 주면 원하는 기준으로 정렬한다.
- **distinct** — equals()(record는 자동 생성된 equals) 기준으로 중복을 판단한다. ✅ 본인 답: "재정의된 이퀄".
- **limit/skip** — limit은 원하는 개수만큼만 가져오고, skip은 원하는 개수만큼 건너뛴다. ✅ 본인 답 그대로.

## 08 최종 연산과 reduce

- **forEach** — 단순 출력 등 부수효과 용도로만 쓰고, 외부 리스트에 결과를 쌓는 데 쓰면 안 된다(안티패턴). 결과를 모으려면 toList()/collect()를 쓴다. (본인 답 "단순 출력에만 쓰라 그러지 않았나" — 방향 정확)
- **count/min/max** — min()/max()는 스트림이 비어있을 수 있어서 값이 없을 가능성 때문에 Optional<T>를 반환한다. count()는 항상 long 하나로 확정되므로 Optional이 아니다.
- **match 3종** — 하나라도 있는지(anyMatch), 전부 다 맞는지(allMatch), 아무것도 없는지(noneMatch). 빈 스트림일 때 각각 `false / true / true`. ✅ 본인 답 완벽.
- **reduce** — identity는 시작값이자 스트림이 비었을 때 돌아오는 기본값, accumulator는 누적값과 다음 요소를 받아 새 누적값을 만드는 함수(예: `(a, b) -> a + b`).
- **기본형 스트림** — mapToInt를 쓰는 이유는 박싱 비용을 피하고 sum()/average() 같은 전용 메서드를 쓰기 위해서. average()의 반환 타입은 OptionalDouble. (본인 답 "OptionalDouble 아닌가" — 정확히 맞힘)
- **summaryStatistics** — 빈 스트림일 때 getMin()은 Integer.MAX_VALUE, getMax()는 Integer.MIN_VALUE가 나온다(getCount()==0 먼저 확인 필요). ✅ 본인 답 완벽.
- **결합법칙** — (a op b) op c == a op (b op c)가 성립해야 스트림을 여러 조각으로 나눠 병렬 계산한 뒤 합쳐도 같은 결과가 나온다. 덧셈·곱셈·max는 성립하지만 뺄셈은 순서에 따라 값이 달라져 성립하지 않는다.

## 09 collect와 컬렉터

- **Stream.toList() vs Collectors.toList()** — Stream.toList()는 수정 불가가 명확한 계약, Collectors.toList()는 가변성이 계약에 없다(구현체에 따라 다를 수 있음). ✅ 본인 답 그대로.
- **toMap** — 중복 키가 생기면 병합 함수 없이는 IllegalStateException이 발생한다(본인 답 "C 또는 I로 시작" — 방향 정확). 병합 함수(3번째 인자)는 실제로 키가 중복될 때만 호출된다.
- **groupingBy 기본값** — 다운스트림을 생략하면 기본값은 **toList()**다(Map<K, List<T>>). 랜덤이 아니다.
- **counting** — 다운스트림으로 쓰면 각 그룹의 개수를 Long 타입으로 세어준다. ✅ 본인 답 그대로.
- **mapping** — 첫 번째 인자는 "각 요소를 어떻게 변환할지", 두 번째 인자는 "변환된 값들을 어떻게 다시 모을지"(재수집 컬렉터).
- **averagingInt** — 입력은 int지만 평균 결과는 소수점이 나올 수 있어서 반환 타입은 항상 Double이다.
- **joining** — delimiter는 요소 사이에 끼울 구분자, prefix/suffix는 전체 결과의 맨 앞/맨 뒤에 한 번만 붙는 문자열. ✅ 본인 답 그대로.
- **다운스트림 컬렉터** — groupingBy가 나눈 그룹 하나하나마다 독립적으로 적용된다(전체 스트림에 한 번 적용되는 게 아님).
- **구체적인 리스트·맵 구현을 가정하면 안 되는 이유** — API가 보장하는 건 인터페이스 타입(List, Map)뿐이고, 구체적인 구현체는 계약에 없어서 나중에 바뀔 수 있기 때문. ✅ 본인 답 방향 정확.
- **toCollection** — 원하는 컬렉션의 생성자 참조(`TreeSet::new` 등)를 인자로 넘긴다. ✅ 본인 답 그대로.
